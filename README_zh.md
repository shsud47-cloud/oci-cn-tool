# oci-cn 完整使用与备份恢复教程（v5.7）

甲骨文云中文管理脚本，替代 oci-helper（Y探长）。基于官方 oci-cli，
密钥加密存放、运行时解密到内存、退出即焚，不对外开放任何端口。

**运行位置：面板机**（主机名 `instance-20260806-1530`，OCI 中显示名 **SingaporeWest-ARM-1**，新加坡西账号，4核/24G，引导卷 200G + 数据盘 fee-volume 50G 挂在 `/data`）。

## 二、启动与菜单

```bash
sudo oci-cn
```
主菜单：`1` 配置列表（进入账号）/ `2` 系统配置 / `0` 退出（清除内存密钥）

选账号 → 选区域 → 账号页：
租户详情 / 实例详情 / 引导卷·存储 / 虚拟云网络 / 流量统计 / 配额查询 / 成本分析 / 切换区域

- 每次操作实例都会列出实例让你手动选编号
- **读取列表时误按的按键会被自动清掉**，只认提示出现之后的输入（粘贴配置/私钥的多行输入不受影响）
- **所有多步输入都支持输 `0` 取消**：任何时候输 `0` 回车即取消当前操作，返回上一级

## 三、统一操作规则

1. **执行前确认**：显示「改前 → 改后」，y 执行；高风险（删除、超免费额度、订阅区域、删盘）要输 yes
2. **输入校验**：数字、范围、端口、协议不合法直接拒绝
3. **"成功"只在回读确认最终状态后才推送**，超时或回读不一致推 ❌
4. **所有改动类推送都带「状态」行**；失败一律 ❌ 并附 OCI 错误原因
5. 实例类推送带公网 IP

## 四、实例操作

| 操作 | 行为与推送状态 |
|---|---|
| 开机/关机/强制关机/重启 | 已是目标状态则跳过；等到 RUNNING/STOPPED（最多 5 分钟），推送状态+IP+耗时 |
| 改配置 | 仅 Flex 可改；超 4核/24G 要 yes；等重启完成，推送实际配置+IP |
| 创建 | 先选**可用域**（多可用域时列出编号选择）→ 实例类型：`1`=免费额度（只显示 E2.Micro/A1.Flex）/`2`=付费（全部机型，免费的置顶标 `[免费]`）→ 机型从 **API 实时读取** → Flex 显示官方规格约束（OCPU/内存范围）→ OCPU/内存**必须手动输入**（无默认值）→ 存储检查（引导卷+块存储卷合计，超 200G 提醒可删未挂载盘）→ 引导卷大小（留空=镜像默认，最小50）→ 子网 → 镜像（全部列出不截断）→ 公钥 → 名称 → 汇总确认 → 等 RUNNING，推送 IP、状态 RUNNING |
| 删除 | 显示 IP；**额外挂着的块存储卷会列出提醒（删实例后它们保留并继续计费）**；**询问是否一并删除引导卷**（y=删除/n=保留，保留会继续计费）；等到 TERMINATED 才推 |
| 改名 | 回读名称一致才算成功 |
| 换IP | 确认后执行；回读确认已绑定；配了 CF 自动改 DNS（成功 N 条/失败的单独推 ❌） |
| 附IPv6 | 确认后执行（子网需已启用 IPv6） |

## 五、引导卷 / 存储

```
 1查看 2扩容 3调性能 4缩硬盘
 5全部盘(含未挂载) 6新建块存储卷 7删除未挂载的盘
 8挂载块存储卷 9卸载块存储卷 0返回
```

| 功能 | 说明 |
|---|---|
| 1 查看 | 选实例看它的引导卷 |
| 2 扩容 | 只能扩不能缩；超 200G 要 yes；完成后要在节点机扩分区（见下） |
| 3 调性能 | VPU 0–120 的 10 的倍数，>10 收费 |
| 5 全部盘 | 扫描所有已订阅区域的引导卷和块存储卷，标出挂在哪台、未挂载、副区域计费；汇总主区域用量/200G；推钉钉 |
| 6 新建块存储卷 | 当前区域新建，按用途命名，不挂载；创建前显示本卷会计费多少 G |
| 7 删除未挂载的盘 | 只能删未挂载的；输 yes；等到 TERMINATED 后推送，停止计费 |
| 8 挂载块存储卷 | 选未挂载的卷 → 选同可用域实例 → 半虚拟化挂载 → 给出节点机整段命令 |
| 9 卸载块存储卷 | 给出节点机整段弹出命令 → 节点机执行后输 yes → 云端卸载 |

### 免费额度规则
- 主区域所有盘（引导卷+块存储卷）合计 **200G 免费**，超出计费
- **副区域的盘全部计费**（约 50G 每月 300 日元左右）
- 引导卷**不能缩**；需要灵活增减的空间用块存储卷

### 扩容后在节点机扩分区
```bash
echo 1 | sudo tee /sys/class/block/sda/device/rescan
sudo growpart /dev/sda 1
sudo resize2fs /dev/sda1
df -h /
```
或在 oci-cn 里重启实例自动撑满。

### 块存储卷命名规则（v4.4 起）
- 新建时**按用途起名**：如 `data`、`backup`、`media`（字母、数字、`-`，最长 16 位），同一区域不能重名
- 这个名字同时用作：OCI 里的卷名 = 盘上的文件系统卷标 = 节点机挂载目录 `/mnt/卷名`
- 按名字认盘，不依赖 sdb/sdc 这类会变的设备名；一台机器挂多块也不会互相覆盖，迁移或删除时不容易弄错

### 挂载（存储 → 8）
oci-cn 云端挂载成功后，终端会显示一整段命令，**登录对应节点机，从 `sudo bash <<'XEOF'` 到最后的 `XEOF` 整段复制粘贴**即可。它会自动：
- 已经挂好的 → 直接提示目录
- 盘上已有同名卷标（重新挂回来的旧盘）→ 直接挂，**不格式化**
- 否则只认「大小一致、没分区、没文件系统、没挂载」的**唯一一块**空盘才格式化；找到 0 块或多块就停下提示
- 挂到 `/mnt/卷名`，写入开机自动挂载（`LABEL=卷名`，带 nofail）

成功只输出一行：`✅ 已挂载到 /mnt/backup，可用 47G`

- Linux 没有盘符，按**目录**使用：只有写到 `/mnt/卷名` 下的文件才存在这块盘上，其他路径仍在系统盘，**不会自动溢出**
- 挂载后哪吒要在节点机执行 `sudo systemctl restart nezha-agent` 才会更新磁盘总量

### 卸载（存储 → 9）与删除（存储 → 7）
1. 先把要保留的文件拷走（**删除后数据永久丢失**）
2. oci-cn 选 9，终端显示一整段命令，**登录对应节点机整段粘贴**：按卷名找到这块盘 → 安全弹出 → 只删除它在开机自动挂载里的那一行；有程序正在使用会提示失败，不会强拔
3. 节点机显示「✅ 已弹出」「✅ 已清理」后，回 oci-cn 输 `yes` 完成云端卸载（输其他任何内容都是取消）
4. 需要停止计费再选 7 删除（OCI 不允许删除挂载中的盘）

> 引导卷（系统盘）不能用这个流程卸载，以上只针对块存储卷。

### 旧方式挂载的盘（v4.4 之前）
以下三块是旧方式挂的：卷标 `data`、目录 `/data`、开机挂载用 UUID：
- 面板机 SingaporeWest-ARM-1：fee-volume 50G
- Kulai-ARM-1：fee-volume-1 50G
- Kulai-ARM-2：fee-volume-1 50G

保持不动即可。v4.4 的卸载命令兼容它们（按新名字找不到时，若本机只有一块卷标 data 的盘，就按旧方式处理并提示）。

如果误弹出了旧盘想恢复（在对应节点机）：
```bash
sudo mount LABEL=data /data && echo "LABEL=data /data ext4 defaults,nofail 0 2" | sudo tee -a /etc/fstab && df -h /data
```

## 十一、Cloudflare 自动更新 DNS

换 IP 后把你域名里指向旧 IP 的 DNS 记录改成新 IP。系统配置 → 5：
- Token（Edit zone DNS 模板创建）
- Zone ID（域名概览页 → API 区域 → 区域 ID）
- 记录类型可选：`A`（默认）/`AAAA`/`A,AAAA`
- 配置时严格验证，Token/Zone ID 无效不会保存；任何一步输 `0` 可取消

## 十二、"保护费"做法（PAYG 账号保持少量真实消费）

- 不要扩引导卷（缩不回去）
- 主区域盘总量超过 200G 的部分、以及副区域的盘才计费，约每 50G 每月 300 日元（约 15 元）
- 用 **6 新建块存储卷**；可以 8 挂到机器上用，也可以不挂
- 不想交了：（挂着的先 9 卸载）→ 7 删除
- 建盘确认页显示「本卷计费 0G」说明在免费额度内，交不了保护费

当前布局：
- 主区域机器：2核/12G/100G 引导卷，剩 100G 免费额度可建数据盘
- 副区域机器：2核/12G/50G 引导卷（这 50G 本身就在计费）
- 古来两个账号：100G 引导卷 + 50G 数据盘（/data，免费额度内）
- 新加坡西（面板机所在）：200G 引导卷 + fee-volume 50G（计费）
- AMD E2.1.Micro 性能太弱且占 47G 免费额度，不开

## 十三、新节点机初始化（参考，在节点机执行）

```bash
# 系统防火墙全放行
sudo iptables -F && sudo iptables -P INPUT ACCEPT && sudo iptables -P FORWARD ACCEPT && sudo iptables -P OUTPUT ACCEPT && sudo netfilter-persistent save

# fail2ban：1 小时错 3 次封 30 天
sudo apt update && sudo apt install -y fail2ban && \
sudo tee /etc/fail2ban/jail.local >/dev/null <<'EOF'
[DEFAULT]
maxretry = 3
bantime = 2592000
findtime = 3600
backend = systemd

[sshd]
enabled = true
EOF
sudo systemctl enable fail2ban && sudo systemctl restart fail2ban && sleep 5 && sudo fail2ban-client status sshd

# XBoard 节点改了 TLS/证书后
sudo systemctl restart xboard-node
```

## 十六、安全机制

- 密钥磁盘加密，运行时解密到 /dev/shm，退出即删
- 单实例锁；连错解密密码 5 次自动删除本地密钥和配置
- 不监听端口、无自动更新、不外传数据
- 面板机只跑 oci-cn 等少量服务，n8n、下载器等常驻服务放其他节点机

## 十七、踩过的坑

| 现象 | 原因 / 处理 |
|---|---|
| 扩容后系统磁盘没变 | 只扩了云端，节点机 rescan + growpart + resize2fs，或重启 |
| 挂了数据盘但空间没变大 | 数据盘按目录使用，只有写到 /data 才用它 |
| 新加账号套餐/租户显示「—」或错位 | v3.9.4 起已修，用「刷新账号信息」 |
| 某账号每次刷 `Warning: ... OCI_API_KEY` | 粘贴私钥时删了标签，v3.9.5 起已屏蔽 |
| 创建 AMD 报 404 | 该区域不提供 E2.1.Micro，先看配额查询 |
| 推送里实例名是「1」之类 | 读取时提前按键被串入，v4.3 起已自动清除 |
| 一台机器挂第二块盘覆盖了第一块 | 旧版都挂 /data，v4.4 起按卷名挂到 /mnt/卷名 |
| 卸载时输 no | 只有 yes 才执行，其他都是取消 |
| 订阅区域失败 | 副区域已满 2 个 |
| HY2 超时但 VLESS 正常 | 证书没申请成功，修好 TLS 后重启 xboard-node |
| 每月莫名的 Block Storage 费用 | 副区域的盘或主区域超 200G，用「5 全部盘」查 |

## 配置恢复（私人仓库）

`server-config/` 是生产机完整配置（14 个租户，私钥加密存放，解密密码 `admin`）。下载仓库后把 `server-config/` 内容拷到 `/root/.oci-cn/`（去掉 README 和 crontab 文件，chmod 700 / 密钥 600），运行 `sudo oci-cn` 输入密码 `admin` 即可使用。详见 `server-config/README.md`。
